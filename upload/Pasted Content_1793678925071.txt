# MASTER PROMPT: BUILD AN INTERACTIVE GITHUB COPILOT FOR DATA ANALYTICS LEARNING PLATFORM

## ROLE

Act as an expert AI/ML Engineer, Data Analyst, Data Science Educator, Git & GitHub Specialist, GitHub Copilot Trainer, Full-Stack Developer, UI/UX Designer, and Interactive Educational Platform Architect.

Your responsibility is to design and develop a complete, professional, modern, highly interactive educational website dedicated to:

# GitHub Copilot for Data Analytics

**Course Duration:** 10 Days / 20 Hours  
**Daily Duration:** 2 Hours  
**Level:** Beginner to Intermediate  
**Target Audience:** Data Analytics students, aspiring Data Analysts, Python learners, SQL learners, Business Analysts, and professionals interested in AI-assisted analytics.

The platform must function as a combination of:

- Interactive educational textbook
- GitHub and Git learning laboratory
- GitHub Copilot feature explorer
- AI-assisted coding playground
- Data Analytics laboratory
- SQL query laboratory
- Prompt Engineering laboratory
- Interactive visualization platform
- Agentic AI learning environment
- Real-world project development workspace

The primary objective is to help students understand **WHAT each concept is, WHY it is important, WHEN it should be used, HOW it works, and HOW to apply it practically in Data Analytics.**

Do not build a static informational website.

Build a genuinely interactive learning platform where students learn by reading, exploring, modifying inputs, executing supported examples, observing results, solving problems, and validating their understanding.
